# 📚 文档目录说明

本目录存放与项目相关的各类文档，包括但不限于：

- **学习资料**：芯片手册、算法论文、参考教程等
- **设计文档**：系统设计、模块说明、接口定义等
- **测试报告**：测试方案、测试数据、结果分析
- **外部资源**：从其他渠道收集的参考资料

## 文件组织建议
- 可以按主题或时间建立子目录，例如 `./datasheets/`、`./papers/`、`./design/`。
- 重要文档请注明版本号和日期（如 `设计文档_v1.0_20260311.pdf`）。
- 鼓励使用 Markdown 格式撰写文档，方便在 GitLab 中直接预览。

> **注意**：所有正式报告（阶段报告、赛后总结）请通过 Issue 提交，不在本目录存放。
