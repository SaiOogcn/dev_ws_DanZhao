# 全国总决赛代码压缩包

本目录用于存放向 **全国总决赛** 提交的最终参赛代码压缩包。

## 📌 代码包要求
- **格式**：ZIP 或 TAR.GZ
- **内容**：整个项目源码，包括算法、嵌入式代码、配置文件、依赖说明等
- **清理**：务必删除临时文件、编译产物、日志、中间文件（如 `.o`、`__pycache__`、`.cache`、`build/`、`dist/`）
- **附加文件**：建议包含 `README-env.md` 说明运行环境、依赖库安装方式

## 文件命名
按照组委会命名规则，建议格式：
```
队伍编号_赛项_代码包_版本号_日期.zip
```
例如：`TJS001_人工智能视觉_代码包_v3.0_20260715.zip`
