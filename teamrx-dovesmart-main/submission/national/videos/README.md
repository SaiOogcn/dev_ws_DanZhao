# 全国总决赛演示视频

本目录用于存放向 **全国总决赛** 提交的演示视频文件及相关说明。

## 📌 视频要求（根据组委会通知填写）
- **格式**：MP4，H.264编码
- **分辨率**：1920×1080 或 4K（请确认）
- **时长**：≤X分钟
- **内容要求**：
  - 需包含车模完整运行过程及关键任务特写
  - 建议加入慢动作或分屏展示创新点
  - 其他补充要求：___________

## 文件命名
按照组委会命名规则，建议格式：
```
队伍编号_赛项_演示视频_版本号_日期.mp4
```
例如：`TJS001_人工智能视觉_演示视频_v2.0_20260715.mp4`

## 大文件处理
- 如果视频超过仓库大小限制，请上传至网盘（百度网盘/阿里云盘等）。
- 在本目录下创建一个 `网盘链接.txt` 文件，写入下载链接和提取码（如有）。
- 同时保留一份低分辨率预览版（可选）。
