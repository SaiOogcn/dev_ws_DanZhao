- **格式**：PDF（必须包含封面页，如有官方模板请使用）
- **页数限制**：≤X页（含附录）
- **内容要求**：
  - 需包含最终系统方案、关键参数、比赛表现分析
  - 鼓励加入迭代对比、创新点说明
  - 其他补充要求：___________

## 文件命名
按照组委会命名规则，建议格式：
```
队伍编号_赛项_技术报告_版本号_日期.pdf
```

例如：`TJS001_人工智能视觉_技术报告_v3.0_20260715.pdf`

## 源文件存档
- 同时保留可编辑源文件（如 Word/LaTeX 源码），命名同上，扩展名为 `.docx` 或 `.zip`。
