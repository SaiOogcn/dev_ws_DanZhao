# 全国总决赛其他材料

本目录用于存放除技术报告、视频、代码包以外的其他提交材料，如实物照片、原理图、PCB工程文件、答辩PPT、展板设计等。

## 📌 材料分类
请根据实际需要创建子目录或直接存放文件，例如：
```
other-materials/
├── photos/ # 实物照片（高分辨率）
│ ├── 整体照片_v2.jpg
│ └── 关键模块特写_v2.jpg
├── schematics/ # 原理图/PCB文件
│ ├── 主控板原理图_v3.pdf
│ └── 主控板PCB源文件_v3.zip
├── presentation/ # 答辩PPT
│ └── 答辩PPT_v3.0.pptx
├── posters/ # 展板设计（如有）
│ └── 展板设计_v2.0.pdf
└── README.md # 本文件
```


## 文件命名
建议采用以下格式：
```
队伍编号_赛项_描述_版本号_日期.扩展名
```

例如：
- `TJS001_人工智能视觉_整体照片_v2_20260715.jpg`
- `TJS001_人工智能视觉_答辩PPT_v3_20260715.pptx`

## 注意事项
- 照片请使用高分辨率JPEG格式。
- 工程文件可打包为ZIP上传。
- 如文件过大，可参照视频处理方式，上传网盘并提供链接。

## 版本记录（可选）
如有多个版本，可在下方记录：
- 实物照片：v1（省赛），v2（新增全国赛特写）
- 原理图：v3（根据全国赛优化）
