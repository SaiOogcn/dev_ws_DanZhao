# 省赛代码压缩包说明

本目录用于存放向省赛/区域赛提交的最终参赛代码压缩包。

## 代码包要求
- **格式**：ZIP 或 TAR.GZ
- **内容**：整个项目源码，包括算法、嵌入式代码、配置文件等
- **清理**：务必删除临时文件、编译产物（如 `.o`、`__pycache__`、`.cache`、`build/` 等）

## 文件命名
按照组委会命名规则，建议格式：
```
队伍编号_赛项_代码包_版本号_日期.zip
```
例如：`TJS001_人工智能视觉_代码包_v2.0_20260520.zip`

## 版本记录
请在下方记录代码包的版本变化：
- v1.0：初版，完成基本功能（日期）
- v2.0：优化算法，修复若干bug（日期）

## 附加说明
- 如需提供代码运行环境说明，可另附 `README-env.md` 文件一并放入压缩包。
- 如使用第三方库，请在压缩包内附上 `requirements.txt` 或说明文档。
