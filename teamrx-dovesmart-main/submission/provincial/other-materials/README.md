# 省赛其他材料说明

本目录用于存放除技术报告、视频、代码包以外的其他提交材料，如实物照片、原理图、PCB工程文件、PPT等。

## 材料分类
请根据实际需要创建子目录或直接存放文件，例如：

```
other-materials/
├── photos/ # 实物照片
│ ├── 整体照片.jpg
│ └── 关键模块特写.jpg
├── schematics/ # 原理图/PCB文件
│ ├── 主控板原理图.pdf
│ └── 主控板PCB源文件.zip
├── presentation/ # 答辩PPT
│ └── 答辩PPT_v1.0.pptx
└── README.md # 本文件

```


## 命名规范
建议采用以下格式：

```
队伍编号_赛项_描述_版本号_日期.扩展名
```

例如：
- `TJS001_人工智能视觉_整体照片_v1_20260520.jpg`
- `TJS001_人工智能视觉_原理图_v2_20260520.pdf`

## 注意事项
- 照片请使用高分辨率JPEG格式。
- 工程文件可打包为ZIP上传。
- 如文件过大，可参照视频处理方式，上传网盘并提供链接。
