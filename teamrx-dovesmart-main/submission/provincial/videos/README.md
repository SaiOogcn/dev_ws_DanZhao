# 省赛演示视频说明

本目录用于存放向省赛/区域赛提交的演示视频文件及相关说明。

## 视频要求（根据组委会通知填写）
- **格式**：MP4，H.264编码
- **分辨率**：1920×1080
- **时长**：≤X分钟
- **内容要求**：
  - 需包含车模完整运行过程
  - 关键任务特写
  - 其他：（请补充）

## 文件命名
请按照组委会命名规则，建议格式：
```
队伍编号_赛项_演示视频_版本号_日期.mp4
```
例如：`TJS001_人工智能视觉_演示视频_v1.0_20260520.mp4`

## 大文件处理
- 如果视频超过仓库大小限制（如100MB），请上传至网盘（百度网盘/阿里云盘等）。
- 在本目录下创建一个 `网盘链接.txt` 文件，写入下载链接和提取码（如有）。
- 同时保留一份低分辨率预览版（可选）。

## 版本记录
如有多个修改版本，请在下方记录：
- v1.0：初版，完成拍摄剪辑（日期）
- v2.0：根据教师意见修改，增加慢动作特写（日期）
