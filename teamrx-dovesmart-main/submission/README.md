# 📦 比赛提交材料指南

本目录用于存放向比赛组委会提交的各类材料（技术报告、视频、代码包等）。请根据比赛阶段（省赛/区域赛、全国总决赛等）在对应子目录中整理文件，并严格按照要求命名和审核。

---

## 🗂️ 阶段划分

根据比赛进程，材料按阶段存放：

- **`provincial/`**：省赛/区域赛阶段（所有参赛队伍必须准备）
- **`national/`**：全国总决赛阶段（仅晋级队伍使用）
- （如有更多阶段，可自行增加，如 `quarterfinal/`、`semifinal/`）

每个阶段目录下通常包含以下子目录（请按需使用）：

```
├── technical-report/    # 技术报告（PDF + 源文件）
├── videos/              # 演示视频（MP4，附说明）
├── code-snapshot/       # 参赛代码压缩包（需清理临时文件）
├── other-materials/     # 其他材料（如实物照片、原理图、PPT等）
```


---

## 📋 提交清单（以省赛阶段为例）

根据本届比赛规则，需要准备以下材料（请队伍根据实际赛项要求补充）：

- [ ] **技术报告**：PDF格式，含组委会要求的封面页（如有模板请使用）
- [ ] **演示视频**：MP4格式，时长≤X分钟，需包含……（具体要求请查阅赛题）
- [ ] **代码压缩包**：整个项目源码，剔除临时文件（`.o`、`__pycache__`、`.cache`等）
- [ ] **实物照片**：3-5张高清JPEG图片（车模整体、关键模块等）
- [ ] **其他材料**：如原理图、PCB工程文件、PPT等（按赛项要求准备）

> **注意**：不同阶段（如全国赛）的清单可能不同，请以组委会最新通知为准。

---

## 🏷️ 命名规范

所有文件请按组委会要求命名；若无明确要求，建议采用以下格式：

  ```
  队伍编号_赛项_材料类型_版本号_日期.扩展名
  ```


例如：
- `TJS001_人工智能视觉_技术报告_v2.0_20260520.pdf`
- `TJS001_人工智能视觉_演示视频_v1.0_20260520.mp4`

版本号建议使用 `v1.0`、`v2.0` 形式，日期格式 `YYYYMMDD`。

## 📌 注意事项

- **文件过大处理**：视频等大文件可上传至网盘（如百度网盘），将链接和提取码写入对应目录的 `README.md` 中。
- **审核流程**：所有材料在提交组委会前，**必须**经过指导教师或助管审核。
- **版本管理**：建议在每个阶段目录的 `README.md` 中记录文件版本、修改日期和主要变更，便于追溯。

---

## 🔍 内部审核流程

每个阶段材料准备完成后，请在项目中创建 **“提交材料审核” Issue**，使用模板 `.gitlab/issue_templates/比赛材料提交审核.md`。操作步骤如下：

1. 进入项目 **Issues** → **New issue**，选择模板“比赛材料提交审核”。
2. 填写基本信息（队伍名称、比赛阶段、计划提交日期）。
3. 勾选已准备好的材料，并附上文件路径（如 `submission/provincial/technical-report/xxx.pdf`）。
4. 进行自检，确认命名、格式等符合要求。
5. 指派给指导教师或助管，等待审核意见。
6. 审核通过后，将最终文件上传至对应阶段目录，并关闭 Issue。

> **注意**：只有经过审核的材料才视为最终有效版本，请勿直接提交未审核文件。
